Self-healing CI · Case study

CI that catches its own gaps — and closes them.

A GitHub Actions pipeline for vibe-tracker that doesn't just fail loudly. When a pull request ships code without tests, it writes the tests, re-runs and re-verifies its own CI, files any real bug it stumbles onto, and — on one label — opens the fix. Every step below actually happened — twice now, on two unrelated features. Every merge stayed in human hands.

Where it started

The loop can't heal a pipeline that doesn't exist yet. The whole apparatus — the Playwright suites, the coverage gate, and the review/heal workflow — was instantiated in a single foundational PR before any of the self-healing runs below could fire.

The unlock

Why the system can close its own loop instead of stalling halfway.

A bot that can re-run its own CI

GitHub deliberately refuses to let a commit pushed with the workflow's built-in GITHUB_TOKEN trigger new workflow runs — a guard against infinite loops. So the first attempt at auto-heal healed the code but its fix landed a gated, never-executed CI run: dead end.

The fix was to push with a GitHub App installation token instead. GitHub treats that as a real actor, so the [auto-heal] commit re-triggers the suite and the pipeline proves itself green — bounded to 3 attempts, and never merging. Humans still own every merge.

The loop reproduces

The run above could have been a fluke. So the next feature was shipped as a deliberate test: the hand-written spec was held back on a sibling branch, leaving the server change bare — to see whether the same gate would catch a feature the pipeline had never touched, and what the bot would write on its own.

Benchmarked against a human

Withholding the spec wasn't an oversight — it was the experiment. A hand-written suite existed the whole time on a sibling branch, so the bot's generated tests could be read side by side with a human's for the exact same feature. PR #15 then brought the human side in: a seeded blocked.sites.json fixture and a hardened spec, 10 tests, full suite green at 42.

The bot didn't just fill the gap. It wrote a suite a reviewer would sign off on and named its own blind spots — concurrent writes, and a case-sensitive /Careers segment it declined to guess at. The gate caught the omission; the heal met the bar the human then held it to.
